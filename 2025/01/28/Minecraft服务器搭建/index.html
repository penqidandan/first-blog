Minecraft服务器搭建

发表于2025-01-28|更新于2025-01-28
|浏览量:

本文档旨在帮助玩家创建和配置自己的 Minecraft 服务器，以便与朋友或全球玩家一同畅享游戏。文档包括从基础安装到高级配置的各个步骤，确保玩家能够顺利搭建、管理并优化 Minecraft 服务器。

硬件要求及软件基础

硬件：

CPU：2GHz以上多核/2.5GHz以上单核 推荐 3.2GHz以上多核的CPU

运行内存：4G及以上 推荐8G以上运行内存

系统：Windows 7 64位及以上

显卡：1G以上显存 的独立显卡 推荐4G以上独显

硬盘：200M以上剩余空间 推荐500M以上

网络：上载/下载 10 Mbps以上

软件：

Java运行环境

服务器核心

官方服：

Mojang官方发布的服务端，不支持插件/MOD，但是支持数据包。

插件服：

插件服是只能使用插件（Plugin）的服务端核心，包括以下几个主流的核心：

  1. Bukkit https://getbukkit.org/

  2. Spigot（Bukkit的分支） https://www.spigotmc.org/

  3. Paper（Spigot的分支） https://papermc.io/downloads

  4. 其他基于Bukkit的插件服

插件服的插件基本通用，版本向前兼容（比如支持1.13的插件，如果没有描述，多半支持1.14及以后的版本）

MOD服：

MOD服是只能使用MOD的服务端核心，根据加载器的不同，分为以下两种核心

  1. Forge https://files.minecraftforge.net/net/minecraftforge/forge/
  2. Fabric https://fabricmc.net/use/

两者的mod不互通

MOD服的连接需要：

  1. 服务端和客户端的加载器版本（Forge/Fabric）一致
  2. 服务端和客户端的服务端MOD同步
  3. 服务端和客户端的服务端MOD版本同步

插件MOD服：

顾名思义，同时支持插件和mod的服务端核心，有以下特点

  1. 性能普遍比纯插件/MOD服差
  2. 并非兼容所有插件和mod（不兼容不一定是不能加载，也可能是某个功能不可使用/使用时出现异常）
  3. 客户端的连接同样需要满足和上述mod服相同的条件
  4. 新手服主强烈不建议使用

包括以下几个主流核心

  1. Mohist （使用Forge的mod和Bukkit插件，支持高版本） https://mohistmc.com/download/
  2. Arclight （使用Forge的mod和Bukkit插件，支持高版本） https://github.com/IzzelAliz/Arclight
  3. CatServer （使用Forge的mod和Bukkit插件） https://catmc.org/
  4. Magma （使用Forge的mod和Bukkit插件） https://github.com/magmafoundation/Magma
  5. Sponge （使用Forge的mod和Sponge插件） https://www.spongepowered.org/

网络连接

内网（LAN）

内网通常指的是局域网（Local Area Network）。在Minecraft中，当你在同一个局域网内的设备之间进行游戏时，就属于内网连接。

  • 内网的特点：
    • 所有玩家设备都连接到同一个局域网内（通常是同一Wi-Fi或同一有线网络）。
    • 不需要通过互联网连接，速度更快，延迟较低。
    • 只要在同一个局域网内的设备可以直接访问游戏服务器。
  • 如何使用内网连接Minecraft服务器：
    1. 服务器端：启动Minecraft服务器并打开”LAN世界”选项。
    2. 客户端：在同一局域网中的其他设备上，可以直接搜索并加入到该服务器。

适用场景：
适合家庭、办公室等小范围的多人联机。所有玩家都连接到同一网络，没有外部玩家参与。

外网（WAN）

外网指的是广域网（Wide Area Network），通常是通过互联网连接的网络。当你希望让互联网上的玩家加入你的Minecraft服务器时，就需要使用外网。

  • 外网的特点：

    • 玩家可以位于不同的地理位置，通过互联网进行连接。
    • 需要通过公网IP地址进行连接。
    • 可能会涉及到端口转发、防火墙配置等网络设置，以确保外部玩家可以访问到你的服务器。

  • 如何设置外网连接Minecraft服务器：

    1. 公网IP：确保服务器有一个公网IP地址（可以通过路由器或使用动态域名解析（DDNS）获得）。

    2. 端口转发：需要在路由器上进行端口转发（通常是25565端口），使外部流量可以通过路由器访问到Minecraft服务器。

    3. 防火墙设置：确保操作系统的防火墙或者路由器的防火墙允许玩家通过指定端口连接到Minecraft服务器。

    4. 适用场景：
      适合远程多人联机，尤其是在玩家位于不同地区时使用。

      内网与外网的区别

      特征 内网 (LAN) 外网 (WAN)
      连接方式 同一局域网内的设备 通过互联网连接（需要公网IP与端口转发）
      访问权限 仅限于同一局域网内的设备 可以让全球的玩家通过互联网连接
      延迟 较低，速度更快 可能受网络质量影响，延迟较高
      安全性 安全性较高，通常不需要额外配置 需要配置防火墙和端口转发来保障安全
      适用场景 家庭、办公室等局部区域内的多人游戏 公网玩家参与，适合大型在线服务器

      如何在Minecraft中实现内网和外网联机：

      • 内网联机：当所有玩家都在同一个局域网内时，可以通过启动LAN世界直接加入服务器，无需配置任何端口转发。
      • 外网联机：如果有玩家在局域网之外，你需要配置端口转发，并且可能需要提供公网IP或使用动态域名（DDNS）服务来确保外部玩家可以访问服务器。

内网穿透（NAT）:

内网穿透（NAT穿透）是一种技术，能够帮助在内网环境下运行的设备与外部网络设备进行通信，尤其是对于那些被路由器和防火墙所隔离的设备。在Minecraft服务器搭建中，内网穿透常用于让外部玩家能够连接到你处于内网的Minecraft服务器，而无需手动配置复杂的端口转发。

为什么需要内网穿透？

在家用路由器的网络环境下，你的电脑通常处于一个私有IP地址（局域网内的IP），而你的公网IP是由路由器分配的。当外部玩家尝试连接你的Minecraft服务器时，由于你所在的局域网是受路由器和防火墙保护的，外部玩家无法直接访问到你的电脑。

内网穿透常用工具

以下是一些常用的内网穿透工具，特别适用于Minecraft服务器：

1. Ngrok

  • 简介：Ngrok 是一种非常流行的内网穿透工具，它可以为你本地的服务器生成一个公网URL，从而让外部玩家连接到你的服务器。
  • 使用步骤：
    1. 在 Ngrok官网 注册并下载Ngrok。
    2. 在命令行中运行 ngrok tcp 25565，其中 25565 是 Minecraft 默认的端口。
    3. Ngrok 会生成一个公网可访问的地址（例如 tcp://0.tcp.ngrok.io:12345）。
    4. 将这个地址发送给外部玩家，他们就可以通过该地址连接到你的Minecraft服务器。
  • 优点：设置简单，不需要更改路由器配置；支持TCP/UDP协议。
  • 缺点：Ngrok 的免费版有连接时长和带宽限制，如果需要长期使用或更高性能，需要购买付费版本。

2. FRP（Fast Reverse Proxy）

  • 简介：FRP 是一个高性能的反向代理应用，可以通过内网穿透将局域网中的服务暴露到公网。
  • 使用步骤：
    1. 下载并配置FRP服务端和客户端。
    2. 在FRP服务器端（公网服务器）配置端口转发规则。
    3. 在FRP客户端（内网设备）配置需要穿透的端口（Minecraft的25565）。
    4. 外部玩家可以通过FRP服务器的公网IP和端口来连接你的Minecraft服务器。
  • 优点：开源免费，支持多个协议和端口转发；适用于需要长时间运行的场景。
  • 缺点：需要一个公网服务器作为中转。

3. ZeroTier

  • 简介：ZeroTier 是一个类似VPN的工具，能在多个设备之间建立一个虚拟的局域网，且无需复杂的网络设置。
  • 使用步骤：
    1. 安装 ZeroTier 客户端并注册一个账户。
    2. 创建一个虚拟局域网（network），并将所有参与游戏的设备加入这个网络。
    3. 所有设备将会获得一个虚拟的IP地址，玩家可以使用这些IP连接到Minecraft服务器。
  • 优点：简单易用，像局域网一样连接，不需要端口转发。
  • 缺点：依赖 ZeroTier 服务器，可能会有一定的延迟。

4. Hamachi

  • 简介：Hamachi 是一个经典的虚拟私人网络工具，可以将计算机连接到一个虚拟局域网中，从而允许远程玩家加入游戏。
  • 使用步骤：
    1. 下载并安装 Hamachi 客户端。
    2. 创建一个新的虚拟网络并邀请玩家加入。
    3. 连接后，玩家可以通过局域网连接方式访问你的Minecraft服务器。
  • 优点：配置简单，适合小规模游戏。
  • 缺点：免费版有连接数量限制，且存在延迟问题。

5. Tailscale

  • 简介：Tailscale 基于 WireGuard VPN，它为不同设备提供一个简单的虚拟局域网，便于内网穿透。
  • 使用步骤：
    1. 在所有设备上安装 Tailscale 客户端。
    2. 注册并创建一个网络，所有设备加入该网络。
    3. 通过 Tailscale 提供的虚拟IP进行Minecraft服务器连接。
  • 优点：非常简单，设置轻松，连接稳定。
  • 缺点：需要持续使用Tailscale的服务，免费版有设备数限制。

内网穿透的优缺点

优点 缺点
1. 无需配置复杂的端口转发 1. 可能会引入额外的延迟或性能瓶颈
2. 解决了外部玩家连接内网服务器的问题 2. 免费工具通常有使用时间、带宽等限制
3. 适用于没有公网IP的用户 3. 长时间使用可能会不稳定
4. 设置过程简单快捷 4. 部分工具可能需要第三方服务器支持

总结

内网穿透技术让你无需更改路由器配置即可让外部玩家连接到你所在的内网服务器。在Minecraft服务器搭建中，使用内网穿透工具可以大大简化设置过程，特别是在没有公网IP或端口转发权限的情况下。选择合适的内网穿透工具取决于你的需求，例如是否需要长期稳定的连接，或是只需要偶尔和朋友一起玩游戏。

服务器插件

Authme

服务器登陆插件，可以在玩家登陆时发送欢迎信息(welcome.txt)，可代替正版验证，但同一个ID在不同的IP视为同一个账户。

SuperMotd

可用于更改在多人游戏栏中的服务器图标，服务器名称，服务器介绍。也可在玩家进入服务器之后发送公告。

GameBox

玩一堆可从一个 GUI访问的库存游戏。

EssentialsX

EssentialsX 是 Spigot 服务器的基本插件，为任何大小和规模的服务器提供核心功能。这些功能包括：

  • 玩家制作的房屋
  • 服务器 Warp 和工具包，服务器范围或每个世界
  • 玩家对玩家的私人消息、传送和传送请求
  • 自定义玩家昵称
  • 各种管理工具，包括踢出、临时禁止、静音和监禁
  • 内置经济功能**，包括标牌商店、命令成本和完整的 Vault 支持**

MultiVerse

Multiverse是在 Bukkit 多世界支持诞生之初创建的。从那时起，它已经发展成为**一个完整的世界管理解决方案！**Multiverse 为您的 Minecraft 服务器提供最易于使用的世界管理解决方案，无论大小，并且拥有 Portals 和 NetherPortals 等出色的插件，还有什么不爱的呢！
